
# DevConnect

Projeto Integrador SENAC ADS

## Tecnologias
- HTML
- CSS
- JavaScript
- Node.js
- Express
- SQLite

## Como executar

1. Instale o Node.js
2. Abra o terminal na pasta do projeto
3. Rode:

npm install

4. Depois:

npm start

5. Abra no navegador:

http://localhost:3000
